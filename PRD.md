# PRD — «F1 Paddock & Spoiler Shield» v1.1

**Дата:** 9 ноября 2026  
**Тип:** клиентское SPA, локальный компаньон сезона Формулы-1  
**Статус:** реализовано, проверено в браузере

---

## 1. Идея и для кого проект

### Личный контекст и проблема
Официальные спортивные приложения перегружены новостями, рекламой и видео блогеров, из-за чего в них трудно быстро узнать базовые вещи: даты этапа и точное время заездов. При этом гонки часто проходят в неудобных часовых поясах, заезды приходится смотреть в записи, а соцсети и сообщества сразу публикуют победителей, уничтожая интригу.

Вторая сложность — коммуникация с друзьями из разных городов. Сложно заранее знать, кто смотрит заезд в прямом эфире, а кто оставил его на вечер. Непонятно, можно ли написать в чат и порадоваться за пилота или это станет спойлером, из-за чего приходится делать лишние рассылки с вопросом «Ты смотришь гонку?».

### Решение
«F1 Paddock & Spoiler Shield» — минималистичный компаньон гоночного уикенда. Сервис концентрируется на главном:
- отображает чистое расписание этапа с адаптацией под нужный часовой пояс;
- скрывает официальные результаты защитной шторкой с замком до ручного подтверждения просмотра пользователем;
- предоставляет панель статусов друзей, по которой сразу видно, с кем можно обсуждать финиш в Telegram, а чей чат закрыт от спойлеров.

### Для кого проект
- **Для себя:** решение личной потребности в удобном расписании без визуального шума и с надежной защитой от спойлеров при просмотре в записи.
- **Для компаний друзей, следящих за Формулой-1:** фанаты с разным распорядком дня и привычками просмотра (в прямом эфире или в записи).
- **Для зрителей с друзьями из разных часовых поясов:** возможность быстро понять статус каждого знакомого без риска раскрыть сюжет заезда и без спама в личные сообщения.

## 2. Функции MVP

### 2.1. Профиль и mock-авторизация

- Никнейм и любимая команда (11 команд), сохраняются в `f1_profile`.
- Кнопка «Изменить профиль», модальное окно, смена акцентной темы.
- Первый вход — mock-модалка без пароля, e-mail и сервера.

### 2.2. Сезон-2026: 23 этапа

- Полный календарь сезона: Австралия → Абу-Даби, раунды 1–23.
- Переключатель этапа в шапке карточки: выпадающий список + кнопки «предыдущий/следующий».
- Выбранный этап сохраняется в `f1_selected_race`; после F5 открывается тот же Гран-при.
- Для каждого этапа:
  - название, раунд, город/страна, автодром, длина круга, круги, повороты, дистанция;
  - 5 сессий (для спринт-уикендов — FP1, спринт-квалификация, спринт, квалификация, гонка);
  - формат «Классический уикенд» / «Спринт-уикенд».
- Для Бразилии сохранена схема Интерлагоса; для остальных трасс — аккуратная эмблема этапа, чтобы не показывать чужую схему.


### 2.3. Время: кастомный пояс, локальное время и время трассы

- Выпадающее меню часовых поясов в шапке с живым поиском по городам и смещениям UTC.
- Переключатель режимов отображения **«Моё время» / «Время трассы»** в блоке сессий.
- В режиме «Моё время» главное время рассчитывается по выбранному пользователем поясу (по умолчанию пояс браузера), дополнительное — время автодрома.
- В режиме «Время трассы» главное время — местное время автодрома, дополнительное — время пользователя.
- Выбор режима и часовой пояс сохраняются в `f1_prefs` (`timeMode`, `userTimezone`) и восстанавливаются при обновлении страницы.
- Время сессий хранится в UTC (ISO 8601) и форматируется через `Intl.DateTimeFormat`.

### 2.4. Spoiler Shield и результаты

Три режима:

| Режим | Поведение |
|---|---|
| 🟢 Live | Спойлеры разрешены, доступно обсуждение |
| 🟡 Без спойлеров | Результаты закрыты, защитные бейджи друзей |
| 🏁 Посмотрел | Итоги открыты, если гонка отмечена просмотренной |

**Правила показа результатов:**

1. Гонка ещё не завершилась → блок итогов **полностью отсутствует**.
2. Гонка завершилась, но просмотр не отмечен → итоги закрыты, победители не видны; текст «Гонка не отмечена».
3. Гонка отмечена, но статус «Без спойлеров» → итоги закрыты; кнопка «Открыть итоги» переводит статус в «Посмотрел».
4. Гонка отмечена и статус Live/Посмотрел → виден официальный подиум.
5. Кнопка «Я посмотрел» в закрытом блоке отмечает гонку и открывает итоги.
6. Для будущих этапов (Лас-Вегас, Катар, Абу-Даби) результаты не показываются.

Итоги — **реальные подиумы сезона-2026** из официальных данных Formula 1 для 20 завершённых этапов. Демо-победители удалены.

### 2.5. Друзья в паддоке

- 3 мока: Алекс (Live), Майя (в записи), Даня (посмотрел).
- Доступные действия оформлены **одинаково** — синей Telegram-кнопкой; различие только в состоянии:
  - Live/Посмотрел → «Обсудить в TG»;
  - Без спойлеров → заблокированная кнопка с замком.
- Переход ведёт **в личный чат** с другом: `https://t.me/<ник>?text=<готовый текст>`.
- Ник из карточки используется в ссылке; при отсутствии ника — fallback на `t.me/share/url`.
- Добавление, удаление, undo-тост, сохранение в `f1_friends`.

### 2.6. Предиктор по этапам

- P1–P3, гонщики сгруппированы по командам.
- Запрет пустых полей и повторов.
- Прогноз сохраняется **для выбранного этапа** в `f1_predictions`.
- При переключении этапа показывается его прогноз; прогнозы не перетирают друг друга.
- Редактирование и сброс.

### 2.7. Источник данных и API

- Встроенный снимок: 23 этапа, 22 пилота, 11 команд, официальные подиумы 20 завершённых гонок.
- Запрос к Jolpica `https://api.jolpica.net/ergast/f1/current.json` с таймаутом 2000 мс.
- API подтверждает сезон/раунд; расписание и результаты остаются локальными для офлайн-работы.
- При недоступности API — «Локальный кэш», интерфейс не блокируется.
- Для будущих этапов результаты отсутствуют; после реального завершения гонки данные обновляются в `js/data.js`.

## 4. Схема `localStorage`

| Ключ | Содержимое |
|---|---|
| `f1_profile` | `{ name, team, onboarded, updatedAt }` |
| `f1_user_status` | `{ mode: "live" \| "recording" \| "watched", updatedAt }` |
| `f1_sessions` | `{ "<raceId>": { fp1, fp2, fp3, quali, race, sprint?, sprintQuali? } }` |
| `f1_friends` | массив друзей |
| `f1_predictions` | `{ "<raceId>": { raceId, p1, p2, p3, savedAt } }` |
| `f1_selected_race` | id выбранного этапа, например `"2026-brazil"` |
| `f1_prefs` | `{ timeMode: "local" \| "track", userTimezone: "Europe/Moscow" }` |
Пример сессий:

```json
{
  "2026-brazil": {"fp1": true, "fp2": true, "fp3": true, "quali": true, "race": false},
  "2026-canada": {"fp1": false, "sprintQuali": false, "sprint": false, "quali": false, "race": true}
}
```

Пример прогнозов:

```json
{
  "2026-brazil": {"raceId": "2026-brazil", "p1": "norris", "p2": "verstappen", "p3": "hadjar", "savedAt": "..."},
  "2026-las-vegas": {"raceId": "2026-las-vegas", "p1": "leclerc", "p2": "piastri", "p3": "hamilton", "savedAt": "..."}
}
```

Миграция: старые плоские `f1_sessions` и одиночный прогноз автоматически переносятся на `2026-brazil` при первом запуске v1.1.

## 5. Пользовательский сценарий (Happy Path)

1. Открыть `http://localhost:5173/`.
2. Первый вход: mock-модалка, имя и команда.
3. По умолчанию выбран ближайший актуальный этап — Сан-Паулу (гонка прошла, пользователь смотрит запись).
4. Статус — «Без спойлеров», 4 из 5 сессий отмечены. Блок итогов закрыт: победители не видны.
5. Открыть меню часовых поясов в шапке, найти нужный город через поиск и убедиться, что время заездов пересчиталось.
6. Переключить время на «Время трассы» — время сессий меняется на местное время Интерлагоса; выбор сохраняется.
7. Выбрать в селекторе «Этап сезона» Лас-Вегас — карточка, сессии и эмблема меняются; блок итогов исчезает, так как гонка ещё впереди.
8. Вернуться в Сан-Паулу, нажать «Я посмотрел» — гонка отмечается, статус переходит в «Посмотрел», показывается официальный подиум: Норрис, Верстапен, Хаджар.
9. Перейти в Лас-Вегас, сохранить прогноз на подиум — прогноз привязан к этапу.
10. Вернуться в Сан-Паулу — там остался свой прогноз и своя отметка гонки.
11. В друзьях нажать «Обсудить в TG» у Алекса — открывается личный чат `t.me/alex_live` с готовым текстом.
12. Нажать F5 — сохраняются профиль, часовой пояс, статус, этап, время, сессии, прогнозы и друзья.

## 8. Риски и ограничения

| Риск | Митигация |
|---|---|
| Статический снимок устаревает после будущих гонок | Обновить `js/data.js`; результаты будущих этапов намеренно отсутствуют |
| Часовые пояса/переходы на летнее время | Время хранится в UTC, отображение через `Intl` |
| API Jolpica недоступен | 2-секундный таймаут, локальный fallback |
| Пользователь не отметил гонку | Результаты закрыты, есть подсказка и кнопка «Я посмотрел» |
| Спойлер через DOM | Клиентская защита, не security-boundary |
| Смена часов вручную | Редактирование ISO-времени в `js/data.js` |
