# DESIGN — «F1 Paddock & Spoiler Shield» v1.1

**Назначение:** дизайн-система мультиэтапного сезонного SPA.  
**База:** тёмная телеметрия F1, цвет = смысл, данные — главный герой.

---

## 1. Принципы

1. **Тёмная телеметрия, а не аркада.** Графитовый фон, тонкие сетки, аккуратные свечения, минимум декоративного шума.
2. **Цвет — это статус и команда.** Янтарный — защита, зелёный — live, приглушённый синий — «просмотрено». Акцент команды окрашивает действия.
3. **Спойлер — не украшение.** Пока гонка не отмечена, победители не видны; для будущих гонок блока итогов нет вовсе.
4. **Один экран — один ответ.** Этап, его даты, время в выбранном поясе, прогресс и доступность итогов понятны без инструкции.
5. **Сезонность.** Переключатель этапов — такой же важный контрол, как сам дашборд.

## 4. Сетка и токены формы

- Shell: 1240px, боковые отступы `clamp(16px, 4vw, 32px)`.
- Hero: `1.55fr / 400px`; на ≤1180 — одна колонка, side-stack в 2 колонки; на ≤900 — одна.
- Карточки: radius 24px; вложенные — 14–18px; инпуты — 10px.
- Отступы: 4/8/12/16/20/24/32/40.

- Breakpoints: 1180, 1020, 900, 760, 560, 390.

## 5. Компоненты

### 5.1. Шапка

Sticky, 76px, blur 18px. Логотип, источник API, часовой пояс браузера, режим щита, профиль-чип с командой. На мобильном источник скрывается, остаются логотип, щит и профиль.

### 5.2. Карточка этапа

- Верхняя строка: бейдж `R##`, **переключатель этапа** (‹ select ›), формат, даты.
- Переключатель: компактный pill 30px; select с 23 опциями; стрелки disabled на краях; на ≤760 занимает всю строку.
- Заголовок: название Гран-при, английское имя, автодром, город/страна.
- Справа: карта Интерлагоса **только для Бразилии**; для остальных — **эмблема этапа**: `R##`, код страны, название, длина/круги. Это честнее, чем показывать чужую схему.
- Статистика: 4 ячейки (длина, круги, повороты, дистанция).
- Прогресс: 5 сегментов, заполняются **по фактическим отметкам сессий**, а не по счётчику; подпись «N из 5».
- Сессии: код, название, статус (Завершено/В эфире/Скоро), дата, время, чекбокс «Посмотрел». На мобильном — двухстрочная сетка.
- Футер: источник и обновление API.

### 5.3. Время

- Сегментированный контрол **«Моё время» / «Время трассы»** (25px, pill).
- В выбранном режиме главное время сессии — соответствующий пояс; второстепенная колонка показывает другой пояс («на трассе» / «у вас»).
- Подзаголовок: «Время в вашем поясе · Europe/Moscow» или «Время на трассе · America/Sao_Paulo».
- Выбор сохраняется (`f1_prefs`) и переживает F5.

### 5.4. Spoiler Shield

- Три сегмента: Live / Без спойлеров / Посмотрел.
- Активный сегмент заливается своим статусным цветом; emoji дублируется текстом.
- Динамическое описание зависит от этапа и факта отметки гонки:
  - гонка впереди — «Результаты появятся после финиша»;
  - гонка прошла, не отмечена — «Результаты скрыты: гонка ещё не отмечена»;
  - отмечена, но режим записи — «Spoiler Shield всё ещё скрывает итоги»;
  - отмечена и Live/Посмотрел — «Итоги открыты».

### 5.5. Результаты

- Блок появляется **только** если гонка завершена и есть официальный подиум.
- Для будущих этапов блок отсутствует полностью — без заглушек и тизеров.
- Если гонка не отмечена: оверлей «Гонка не отмечена», кнопка «Я посмотрел»; победители скрыты blur + `inert` + `aria-hidden`.
- Если отмечена, но статус «Без спойлеров»: оверлей «Spoiler Shield активен», кнопка «Открыть итоги» переводит статус в «Посмотрел».
- Если открыто: 3 строки подиума с командным цветом и временем/отставанием, тег «Formula 1», подпись «Официальный результат».
- Никаких демо-победителей и быстрого круга с выдуманными данными.

### 5.6. Друзья

- Карточки с верхней полосой статуса, аватаром по хешу имени, бейджем.
- Доступные действия (Live и Посмотрел) — **одинаковые синие Telegram-кнопки**; различие статусов передаётся бейджем и текстом.
- Друг «в записи» — янтарная защитная карточка, заблокированная кнопка с замком и подпись «Смотрит в записи. Чат закрыт от спойлеров».
- Ссылка ведёт в личный чат: `https://t.me/<handle>?text=<encoded>`; ник берётся из карточки.
- Форма добавления, удаление, undo-тост.

### 5.7. Предиктор

- Бейдж раунда динамический (`R##` выбранного этапа).
- Три селекта P1–P3 с группировкой по командам.
- Валидация повторов; сохранение **по этапу**; карточка с пилотами, командой и временем фиксации.
- При переключении этапа форма/карточка обновляются.

### 5.8. Кнопки и бейджи

| Вариант | Вид | Применение |
|---|---|---|
| Accent | градиент команды | Главное действие |
| Secondary | surface-2 | Вторичное |
| Ghost | прозрачный | Отмена/сброс |
| Telegram | `#229ED9` | Обсуждение |
| Locked | янтарная подложка | Заблокированный чат |

Тег источника — голубой `info`; тег демо больше не используется.

## 6. Состояния и motion

- Hover: 160 мс, `translateY(-1px)`.
- Переключение статуса/времени: 220 мс.
- Прогресс: 420 мс.
- Модалки: 240 мс, fade + scale/sheet.
- `prefers-reduced-motion` отключает пульсации и анимацию трассы.

---

## 7. Доступность

- Нативные `button`, `select`, `input`; кастомные чекбоксы сохраняют нативный input.
- Статусный переключатель — radiogroup + aria-checked + стрелки.
- Модалка: focus-trap, Esc, возврат фокуса, `inert` на header/main/footer.
- Ошибки форм: `aria-invalid`, `aria-describedby`, role=alert.
- Скрытые результаты: `inert` + `aria-hidden`.
- Тосты: `aria-live=polite`.
- Цвет не единственный носитель: подписи и иконки дублируют смысл.

## 9. Реализация стилей

Используется собственная CSS-дизайн-система с Tailwind-совместимыми токенами. Причина: приложение должно запускаться офлайн без CDN и сборщика; Tailwind Play CDN компилирует стили в браузере и ломает вид без интернета. Все токены (`--bg`, `--surface`, `--accent`, spacing 4px, radii) переносятся в `theme.extend` при переходе на Vite + Tailwind без изменения визуала.
