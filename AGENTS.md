# AGENTS.md — F1 Paddock

Клиентский SPA сезона-2026 без сборки, зависимостей и бэкенда.

## Перед изменениями

Прочитать в таком порядке:
1. `README.md` — запуск, возможности, ключи `localStorage`, ограничения.
2. `ARCHITECTURE.md` — фактическая реализация, схема данных, миграции, поток сохранения.
3. По задаче: `PRD.md` (границы продукта), `DESIGN.md` (UI, темы, адаптив), `CREDITS.md` (источники трасс и данных).

Источник истины — код. Номера строк в `ARCHITECTURE.md` могут смещаться; сверяйся с файлами.

## Устройство и правила

- Подключение: `index.html` → `js/data.js` → `js/tracks.js` → `js/storage.js` → `js/app.js`. Это обычные `<script>` без модулей; порядок и глобальные `window.F1_*` менять нельзя.
- `js/data.js` — справочник: 23 этапа, 22 пилота, 11 команд, 20 официальных подиумов; у 3 будущих этапов `results: null`. `js/tracks.js` — схемы по `race.slug`, файлы в `assets/tracks/*.webp`.
- Jolpica API — необязательная проба с таймаутом 2000 мс. Она не заменяет локальные данные и не должна блокировать рендер.
- `js/storage.js` — единственный слой записи в `localStorage`: 7 ключей `f1_*`, нормализация при чтении, memory-fallback. Профиль хранит `telegram`, `authMethod`, `signedInAt`; для входа есть `isSignedIn`, `saveTelegramAuth`, `logoutProfile`. Новое поле = нормализатор + метод `F1Store.save*` + обновление таблицы в документации. Прямой `localStorage` допустим только в pre-paint скриптах `index.html`.
- `js/app.js` — один IIFE примерно на 2,6 тыс. строк: `state` → `render*()` → `innerHTML`. Правки делать локально в существующем стиле, без полного рефакторинга.
- Пользовательские строки в HTML обязательно через `esc()`; текст тостов — через `textContent`.
- Время хранится только в UTC (`ISO 8601`), форматируется через `Intl` и `race.localTimezone`. Локальное время в данные не записывать.
- Темы — `data-theme` на `<html>` + CSS-переменные; командный акцент — `data-team`. Не хардкодить цвета, проверять обе темы. Не удалять pre-paint скрипт темы.
- Пока `f1_prefs.theme === null`, тема следует системной `prefers-color-scheme` и слушает её изменения (`initSystemThemeListener`). Первое ручное переключение обязано записать явный `dark`/`light` в `f1_prefs`; не сбрасывать его в `null` без запроса.
- Вход через Telegram — только демо: `MOCK_TELEGRAM_CODE = '1234'` и `TELEGRAM_BOT_HANDLE` живут в `js/app.js`, в `localStorage` не пишутся. Реального Bot API, сообщений и проверки ника нет; не добавлять сетевые вызовы под видом авторизации.
- `f1_profile.telegram` — единственный признак входа (`isSignedIn`). Верный код сразу вызывает `F1Store.saveTelegramAuth`; имя/команда сохраняются на шаге 3. «Выйти» вызывает `F1Store.logoutProfile` и очищает только `telegram`/`authMethod`/`signedInAt`; прогнозы, сессии, статус, друзья, тема, имя и команда должны сохраняться.
- Степпер `#authStepper` показывать только в сценарии входа (`telegram`, `code`, `profile` после верного кода). В редакторе уже авторизованного профиля (`modalMode === 'edit'` + `isSignedIn`) он скрыт.
- Spoiler Shield: для будущей гонки блока итогов нет; для непросмотренной или `recording` победители не видны. Не выводить имена победителей в соседний текст, `aria`, тосты и ссылки. Сохранять `inert`, `aria-hidden` и focus-trap.
- Схемы трасс берутся из `window.F1_TRACKS` по `race.slug`; отдельного флага наличия карты в `data.js` нет.
- Статическая разметка `index.html` свёрстана под Сан-Паулу; стартовый этап вычисляется по дате в `app.js` и перерисовывается. Не считать HTML-дефолты данными.
- Интерфейс только на русском (`ru-RU`), офлайн, без CDN, внешних шрифтов и фреймворков. Новые результаты — только из официальных источников, без выдуманных данных.
- Адаптив: 360, 390, 768, 1024, 1440 px; горизонтального скролла быть не должно.

## После доработки

1. Запустить сервер и открыть http://127.0.0.1:5173/.
2. Проверить консоль браузера: ошибок и необработанных исключений нет.
3. Пройти затронутый сценарий и базовые:
   - переключение этапов (дропдаун и ‹ ›), спринт и классический уикенд;
   - четыре состояния Spoiler Shield;
   - «Моё время / Время трассы», часовой пояс, `.ics`;
   - прогноз по этапу, запрет дублей, сохранение после F5;
   - друзья: добавление, удаление, undo, ссылка `t.me`;
   - тема: системная при `theme: null`, ручное переключение фиксирует `dark`/`light`, сохранение после F5, отсутствие вспышки;
   - вход: гость → ник → неверный код → `1234` → имя и команда → F5 → редактор профиля без степпера → выход; после выхода данные на месте;
   - шапка: гостевая и авторизованная кнопки, `@ник`, отсутствие переполнения на 360 px.
4. Проверить пустой `localStorage` (первый запуск/онбординг) и миграцию старых данных, включая `f1_profile` без Telegram-полей.
5. Для правок данных: 23 этапа, 20 результатов, 3 `results: null`, у каждого `slug` есть файл схемы.
6. Обе темы на 360/390/768/1024/1440 px — без переполнения.
7. Смоук-проверка сервера:

```powershell
Invoke-WebRequest http://127.0.0.1:5173/ -UseBasicParsing | Select-Object StatusCode
```
